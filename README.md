# 한글로망 언어정보 연구 (HanGwr)

훈민정음의 소리-글자 대응 원리를 국제 표기, 좌표 주소, 도량형, 음성 분석에 적용하는 개인 연구의 자료와 도구를 모은 저장소입니다.

연구자: 한글로망

## 무엇이 들어 있나

| 폴더 | 내용 |
|---|---|
| [`docs/`](docs/) | **연구 정리 문서**. 핵심 관점(음성은 공간 기반 상대 정보), 계층 정보 모형, 한글로망 표기, Glo100 좌표 주소, 정음 조표와 표기 규칙 초안, 정음 도량형, 각론(인지 신호 선택의 기초 연구), 측정 근거, 기원 가설. [바로 읽기](docs/research.md) · PDF · 워드 |
| [`textbook/`](textbook/) | **정음 발음 훈련 교재**. 정음 궤적 추적기로 모음, 복모음, 장음, 자음, 음성 호출을 단계별로 연습하는 13개 과와 외국인 학습자 과정, 기록지, 사례 보고서 양식 |
| [`tracker/`](tracker/) | **정음 궤적 추적기**. 녹음에서 F0, F1, F2를 재어 조음 공간의 길이(L1, L2, L0c, P0c)로 바꾸고 궤적을 그리는 연구용 도구 (시운전 단계) |
| [`tools/`](tools/) | **Glo100 좌표 주소 변환기**(좌표 ↔ 음절 주소, 음성 호출, 확인 음절), **정음 단위 변환기**(SI 단위 ↔ 정음 음절) |

## 쓰는 법

모든 도구는 HTML 파일 하나로 되어 있어 설치가 필요 없습니다.

1. 원하는 파일을 내려받습니다. 파일 화면 오른쪽 위의 내려받기 단추를 누르면 됩니다.
2. 내려받은 HTML 파일을 브라우저로 엽니다.

## 핵심 개념 한눈에

- **천지인 모음 십자:** 모음은 턱의 개방·전후진과 혀의 위치로 정해지는 2차원 공간의 위상이다.
- **코러스 공간:** 대화 속에서 공간이 옮겨 가고 줄어들어도 십자 틀이 함께 움직여, 틀 안의 상대 위치로 소리가 식별된다.
- **접기와 펼치기:** 정음은 규칙으로 복원되는 것(장음, 한국어 복모음)은 한 음절로 접고, 복원되지 않는 것(영어·중국어의 두 모음 현상)은 두 모음으로 펼쳐 적는다.
- **판정 순서:** 쉽고 확실한 특징(소리 유무, 유성, 소음)부터 섬세한 특징(조음 위치)으로 단계적으로 좁힌다.
